## List of files contained in this folder

- **zebrafish_eye_confocal.brim.zip**, a 3D dataset of a zebrafish eye acquired with a confocal spontaneous Brillouin setup and previously published in [“A 3D Brillouin microscopy dataset of the in-vivo zebrafish eye”](https://doi.org/10.1016/j.dib.2020.105427).
