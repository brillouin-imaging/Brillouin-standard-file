# Documentation Overview

This folder contains the `.brim` file format specifications.

The main entry point is [brim_file_specs.md](brim_file_specs.md), which references the other supporting documents.

Files in this folder describe the latest version of the specification.
Versioned subfolders (for example, `v0.1/`) capture the specification at a specific release.

Before starting a new version, a Git tag for the current version is released (for example, `v0.1`) so the repository state
for that release can be referenced easily.
